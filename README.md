This is the shared repo internal to the ATOM team. ATOM is a research community centered around the development of an agent foundation model.

At the time of writing, this repo contains: 
- ATOM's mission
- Programs which are roadmaps written by members of the team, laying out possible paths to fulfill our goals, aiming to organize and direct our work
- Project planning, for lists of projects worth considering to undertake and prioritize
- Org for helpful docs about how ATOM runs as a team, including a template for hiring, some team policies and processes
- Public drafts for shared documents we want to publish: e.g. a public roadmap.
- Archive for retired documents | date-stamped YYYY-MM_title
